# Django веб-интерфейс для системы управления зоопарком

Добавлен Django клиент-серверный веб-интерфейс для системы управления зоопарком. Оба интерфейса (CLI и веб) используют общий код, то есть бизнес-правила реализуются один раз и повторно используются в обоих интерфейсах

## Описание

Приложение предоставляет интерфейс для управления следующими сущностями:

- Вольеры и животные
- Ветеринары и экскурсоводы
- Экспозиции и привязка вольеров
- Экскурсии и посетители
- Мероприятия и посетители
- Журнал ветеринарных осмотров

Вся бизнес-логика реализована в модулях `src/`, а Django-приложение `zoo_web` выполняет отображение, обработку форм и сохранение данных.

## Структура проекта

- `manage.py` — Django entry point
- `mysite/` — настройки Django
- `zoo_web/` — Django-приложение с маршрутами, представлениями и шаблонами
- `src/` — доменная модель зоопарка, использующаяся в лабораторной работе №1
- `zoo.json` — файл хранения данных

## Страницы веб-интерфейса

- `/enclosures/` — управление вольерами и животными
- `/staff/` — управление персоналом и ветеринарными услугами
- `/vet-logs/` — просмотр ветеринарных логов
- `/expositions/` — управление экспозициями
- `/tours/` — управление экскурсиями
- `/events/` — управление мероприятиями

## Установка и запуск

1. Активируйте виртуальное окружение (если используется):

```bash
source .venv/bin/activate
```

2. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

3. Запустите сервер Django:

```bash
python manage.py runserver
```

4. Откройте приложение в браузере:

```text
http://127.0.0.1:8000/
```
